# The user can change the initial conditions

- Status: Accepted
- Date: 2026-11-21
- Source: human in chat (Claude Code session)

## Decision

In the demo, a person can change the initial variables of the simulation and run it again. The 3D scene shows the new result.

## Why

A human said: "tienes que poder cambiar las variables iniciales". A fixed replay is a video, not a simulation. The "what if" is the wow moment (for example: the alert 20 minutes earlier).

## What it means for agents

- Pick 2 to 4 initial variables that the story needs (for a fire: ignition point, wind, alert time, one street open). Use large controls, for a projector.
- A change must give a new result in the 3D scene in seconds, not minutes.
- Do not add variables that the pitch does not use.
